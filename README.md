# .github

Det här repot hör till organisationen [Rita Plan](https://github.com/ritaplan) och ger den en profil på GitHub.

- [`profile/README.md`](profile/README.md) är texten som visas på organisationens [förstasida](https://github.com/ritaplan).
- Här kan också gemensamma filer för alla organisationens repon läggas, till exempel standardmallar för ärenden.

## Projekt

- [Rita Detaljplan](https://github.com/ritaplan/rita-detaljplan): QGIS-plugin för att rita detaljplaner och plankartor.
- [Rita Översiktsplan](https://github.com/ritaplan/rita-oversiktsplan): QGIS-plugin för att rita översiktsplaner.
